# M07 Mini-Game Source Map

This map stays as source evidence only; its commands and paths no longer exist.

Linear milestone: M07. Manual UI approval remains required for JIP-825, JIP-830, and JIP-835.

This map is the durable source contract for Trivia, Funky Monkey Melody, MusiCards Memory, Find Me On The Tree, and Flying Instruments. The extractor is `app/scripts/extract-m07-source-assets.mjs`; run it from `app/` with `npm run assets:m07`. Generated audit evidence is written to ignored `app/generated/m07-source-extract/`, and source-local runtime promotions are written to `app/src/assets/m07-source/`.

The selector is a distinct root-frame-1 state; choosing a level advances the remake into the root-frame-2 game instead of displaying both states together. It parses all 8 beginner, 8 easy, 10 intermediate, and 10 advanced sequences. Each token selects the exact bundled note, length suffix, and delay; pointer/keyboard input is checked one note at a time, matching sprite `makaka` id `0170`'s `check` frame: a wrong note follows its `wrong` animation and decrements `cur_note` to retry the same position rather than exposing invented `TRY AGAIN`/`CONTINUE` copy. ## MusiCards Memory

The source initializes level 1 with five pairs, four columns, three rows, and `errornum = pairs + Math.floor(pairs / 2)`. Each mismatch consumes one error; reaching zero disables card input and exposes `PLAY AGAIN`. Each completed level adds one pair until 18 pairs; completing the 18-pair level grants game key 2. Exact visible source labels include `errors left :`, `level :`, `NEXT LEVEL`, `NEW GAME`, and `PLAY AGAIN`.

Card face sprite id 57 has 18 frames. Frames 1-16 use recoverable child shapes 26, 28, 30, 32, 34, 36, 38, 40, 42, 44, 46, 48, 50, 52, 53, and 55. Frame 17 intentionally reuses source shape 36 and therefore has pixels identical to face 6, while frame 18 uses recoverable shape 56. All 18 are promoted under their correct frame-local names. Sprite id 61 renders the exact 37 x 52 source card back. The runtime shuffles two of each active pair for every board, uses the original level/error rules, plays the bundled sound for each face, and exposes the source assets rather than generic card art. Tests inject a fixed random source so shuffle assertions remain deterministic without freezing gameplay.

The full root render writes no PNG with the local missing-JPEG build. The retained gap is exact Flash display-list/card-flip animation; all 18 source face states now have correctly named child-layer promotions.

## Flying Instruments

This route did not exist before M07; the disabled main-room source hotspot is now routed. The source contains a four-by-seven play grid, three levels, `START`, `RESUME`, `HELP`, and `CHOOSE A GAME TO PLAY`. Source values set `maxInst` to 17 for level 1 and 8 for levels 2 and 3. The repaired source images promoted for runtime use are flute, oboe, clarinet, bassoon, harp, two pianos, drum, cymbals, double bass, cello, violin, trumpet, trombone, French horn, tuba, and the source star.

Embedded export sounds were recovered directly rather than substituted. The source logical order is flute, clarinet, oboe, bassoon, harp, piano, harpsichord, timpani, cymbals, double bass, cello, violin, viola, trumpet, trombone, French horn, and tuba. IDs 1-4 map to woodwinds, 5 and 10-13 to strings, 6-9 to percussion, and 14-17 to brass; each instrument uses the same-numbered `sound#` export. Viola is recovered from vector child shape 48 because its source frame has no repaired JPEG3 peer.

The runtime uses all 17 source instruments for level 1. The Flash chooses randomly among four eight-instrument arrays for levels 2 and 3; the deterministic remake uses the first recovered array for each level: level 2 `[17, 6, 8, 12, 14, 16, 7, 5]` and level 3 `[17, 6, 8, 1, 12, 16, 7, 5]`. Reaching the end of an active set only enters the source `playAgain`/`TRY AGAIN` state. It does not grant game key 3.

Child probes recover the play surface that the failed root render concealed. Sprite id `0172`, placed at root x `326.25`, y `252.00`, scale `0.469`, is the blue perspective room; its root CXForm multipliers green `0.6` and blue `0.9` are applied during promotion. Grid sprites `0320`, `0324`, and `0325` contain the exact four-by-seven white/orange cell art and are placed at x `204.95`/`204.90`, y `20.05`, scale `0.917`. Level button sprites `0203`, `0207`, and `0211`, controller sprite `0165`, score sprite `0170`, and magic-key sprite `0318` also flatten sufficiently for correctly named runtime promotions. `START`, `RESUME`, and `HELP` full buttons do not flatten, so the runtime composes their recoverable body and text children where used. The same child-layer pass promotes pause body shape `0145` and the normal `TRY AGAIN` body/text pair `0228`/`0229`; pause edit-text ids `0142`-`0144` remain a provenance-annotated DOM label because the installed renderer does not flatten dynamic text.

The recovered ActionScript starts each falling instrument in column 2, row 0; uses four columns and rows 0 through 6 at 60-unit spacing; exposes left, right, and down controls; and derives its continuous fall step from `speed = 1.45`, `speedFactor = 3`, and a 25 ms interval. The remake advances one 60-unit row every 345 ms, supports the same pointer and arrow-key movement, pauses/resumes, locks on the lowest available cell, and plays the same-numbered embedded `sound#` export on spawn. `checkSolution` compares the landed cell with the cell directly below; equal families enter the source `match` state and clear both cells after the recovered 1000 ms delay. Each of the two matched cells calls `addSeconds(0.5, 1)`; `addSeconds` applies `seconds += 2 * amount * level * 4`, so a cleared pair scores exactly `8 * level`. Score sprite `0170` initializes `requiredScore = 300`, and `updateHighest` is the only path that calls `saveKey3.exe`, pauses play, exposes the key, and sets `gameKey3` after the score reaches that threshold. The runtime therefore keeps a session score across replayed sets and grants key 3 at 300 rather than at ordinary set completion.

The exact full-render probe still produces a 640 x 480, 406-byte transparent PNG while reporting missing JPEG support and unknown child IDs. The retained gaps are the original sub-row Flash interpolation, the cat narration/timeline, randomized shorter-level array choice, legacy external score persistence beyond the current app session, and full flattening of button-only exit/help children and pause dynamic text. The chooser/play split, source room and grid, falling/locking/matching behavior, arrow controls, score formula, instrument art/audio, `TRY AGAIN` state, and 300-point magic-key gate are no longer fallbacks.
