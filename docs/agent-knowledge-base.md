## Reproducible Evidence Commands

Run from `app/`:

```sh
npm run assets:nutcracker-swf
npm run assets:nutcracker-ui
npm run assets:nutcracker-actors
npm run assets:nutcracker-jpeg3
npm run assets:certificates
npm run assets:source-atlas
npm run assets:shell-reference
```

The SWF pass writes ignored proof artifacts to `app/generated/nutcracker-source-extract/full-swf-pass/`:

- `manifest.json`
- `dumps/*.placements.txt`
- `dumps/*.actions.txt`
- `dumps/*.text.txt`
- direct lossless PNG extraction records

The JPEG3 pass writes ignored repaired image proof artifacts to `app/generated/nutcracker-source-extract/direct-image-tags/`.

The shell/reference pass extracts the final valid `Nutcracker2.exe` payload, locks the `playRoom` frame and button evidence, captures projector/intro dumps under `app/generated/shell-reference-source-extract/`, and promotes correctly named intro, room, Listening Room frame, and gramophone assets under `app/src/assets/source-scenes/`.

The certificate pass extracts the appended Flash payloads from `analysis/setup/app/fscommand/n_certificate.exe` and `nc_certificate.exe`, writes ignored projector/SWF/action/text/display-list proof under `app/generated/certificate-projectors/`, and promotes only the intact Nutcracker-specific sprite id `0018` certificate to `app/src/assets/nutcracker-source/nutcracker-club-certificate.png`.

The actor promotion pass reads the ignored SWF output and writes committed actor assets to `app/src/assets/nutcracker-source/song#-track#-actor.png`.
It intentionally skips copying when ImageMagick reports the selected generated PNG is pixel-equivalent to the committed target, because `swfextract` can rewrite identical indexed PNG art with different bytes.

The UI promotion pass currently copies source UI bitmap evidence such as `song1__song/lossless-39.png` into correctly named committed assets like `song-curtain-scallop.png`. It also extracts/renders recoverable song `courtain` child shapes id `0038`, `0040`, and `0041` from base sprite id `0042`, applies the source `0040` CXForm add `0 102 255 0`, and promotes `song-curtain-fill.png`, `song-curtain-curve-cxform.png`, and `song-curtain-stars.png`; extracts/renders source song-control shapes `0119`, `0126`, and `0113` for `song-control-help-body.png`, `song-control-button-body.png`, and `song-play-again-button-body.png`; extracts/renders `nutchooser.swf` background shapes id `0016`, `0017`, and `0018` from composition sprite id `0021`, applies the id `0017` source CXForm add values `143 60 -10 0`, recreates the JPEG3-backed shape id `0020` from bitmap id `0019` with CXForm `mul 0 0 0 1` / `add 255 51 153 0`, and promotes `chooser-hallway-fill.png`, `chooser-hallway-portal-cxform.png`, `chooser-hallway-vector.png`, and `chooser-hallway-tint-cxform.png`; extracts/renders sprite `0068`, trims it, applies the root placement CXForm, and promotes `chooser-instruments-cxform.png`; extracts/renders `nutchooser.swf` shape id `0201` to promote normal visible `chooser-help-button-art.png`; extracts/renders `nutchooser.swf` shape id `0205` and text id `0204` to promote the composed normal visible chooser `quiter` as `chooser-exit-button-art.png` plus `chooser-exit-label.png`, because text id `0203` is the blue `buttonOFF` EXIT label and full button id `0206` currently renders as a 1 x 1 placeholder; extracts/renders chooser `magicKey` sprite id `0213` in a translated wrapper and promotes `chooser-magic-key.png`. ## Things Already Learned The Hard Way

- M08 extraction is centralized in `npm run assets:m08`. It hash-locks 34 SWFs, parses actions/placements/text, extracts 112 top-level JPEG3/lossless images, 3 verified root streams, 205 standalone sounds, and 77 runtime companions, and writes the durable manifest under ignored `app/generated/m08-source-extract/`. Backup files and alternate Children's Album WAV copies stay in the authoritative source tree rather than being duplicated into runtime assets. The script preflights every source/companion and every SWF hash before removing only its owned generated/promoted roots for rebuilding. Use `docs/m08-mini-games-source-map.md` and `app/src/assets/m08-source/`; do not reconstruct these families from filenames or generic game conventions.
- A SWF DefineSound id is not a semantic game id. Read `EXPORTASSETS` and the corresponding `attachSound` calls before connecting extracted `sound-N.mp3` files. M08 caught three concrete traps: Loopy visible tracks 1..8 map to sound ids 9..2, Orchestra `s1..s18` maps to `[17,11,14,19,8,13,9,3,15,7,16,18,1,2,5,6,12,4]` with `badInst` at 10, and Nut House mirror previews/feedback use room-local export maps. Keep raw provenance assets committed, but narrow eager Vite globs to semantic aliases and actually used audio so evidence files are not shipped in the desktop bundle.
- An `swfextract` inventory line saying `MP3 Soundstream` is not proof that `swfextract -m` can produce a file. Children's Album, the Loopy games, Alice 10-12, and the Nut House rooms can report `Soundstream is not mp3 (2)` or `Didn't find a soundstream`; record `blocked` unless the target exists and is hashed. Continue with standalone `DefineSound` extraction rather than failing the entire source audit.
- M08 root renders are mostly diagnostic failures, not promotable screenshots. Children's Album, Orchestra, all eight Loopy boards, all 12 Alice puzzle boards, and all eight Nut House rooms crash with `SIGSEGV` or produce no usable PNG. Toy Soldiers renders only staff primitives because button id 0030 has an unresolved child; Waltz renders only a gray gradient; the Alice chooser renders only an incomplete ring. Inspect and promote child JPEG3/lossless/audio/action/text evidence, attach exact DOM fallback provenance, and do not call those partial outputs full scenes.
- Several M08 stage/frame children decode as black alpha/color-transform inputs because their source appearance depends on parent CXForms. Keep the correctly named source-local promotions as provenance, but do not claim exact color/display-list parity until the nested transforms can be replayed. Identical pixels or hashes across Alice puzzle groups do not authorize misleading shared names: games 01-03, 04-06, 07-09, and 10-12 are four byte-identical groups, yet each runtime import remains puzzle-local.
- Preserve M08's recovered rule boundaries exactly: Children's Album patterns are the eight bits in `games/data/childrensalbum.txt` and all doors grant key 6; every Loopy tune uses tracks 1, 3, 5, and 7 and tune 8 grants the legacy overlapping key 3; Orchestra uses 18 prompts in source order and grants key 4; Toy Soldiers expects `[1,2,3,4,5,6,7,8]` but has no key; every Alice combination is `[1,1,1]` and has no key; Nut House mirrors are `[8,3,1,7,6,4,5,2]`, persists `openDoor`, and room 18 grants key 7. Waltz is a 785-frame audio timeline without recovered gameplay, so do not invent a win condition.
- M07 mini-game extraction is centralized in `npm run assets:m07`. It locks five SWF hashes, repairs JPEG3 alpha, renders recoverable child shapes, exports embedded trivia/flying sounds, copies source-bundled Melody/Memory/Tree audio, and must report 5 SWFs, 39 source images, and 112 companion files. The extractor clears only its owned generated/promoted roots before rebuilding; without that cleanup a deleted mapping can survive as a stale runtime asset and make drift checks pass falsely. Do not rebuild these routes from copied data alone; use `app/src/assets/m07-source/` plus `docs/m07-mini-games-source-map.md`.
- Keep source-local stage/frame promotions for Melody, Memory, Tree, and Flying Instruments even when `compare -metric AE` says they are pixel-identical. Their source symbols and scenes differ; provenance is part of the runtime contract.
- Full `swfrender` probes for Trivia, Melody, Memory, and Tree can report missing JPEG support and write no PNG. Melody additionally reports `INVALID GRADIENT` and unknown child IDs. Flying Instruments can report missing JPEG/unknown children and write a transparent 640 x 480, 406-byte PNG. Record those exact results as display-list/timeline gaps; inspect and promote JPEG3, lossless, shape, text, action, and placement children before accepting any fallback.
- Memory card sprite id 0057 is not an excuse to draw generic cards when the parent cannot flatten. Frames 1-16 use shapes 0026, 0028, 0030, 0032, 0034, 0036, 0038, 0040, 0042, 0044, 0046, 0048, 0050, 0052, 0053, and 0055; frame 17 intentionally reuses shape 0036 (pixel-identical to face 6), and frame 18 uses shape 0056. Promote all 18 under frame-local names. Sprite id 0061 renders the exact 37 x 52 card back. The source error formula is `pairs + Math.floor(pairs / 2)`, not `pairs * 2`, and zero errors leads to `PLAY AGAIN` with card input disabled. Source ActionScript assigns random `chance` values before `sortOn`, so runtime boards must shuffle; inject randomness in unit tests rather than freezing production card order.
- Tree option placement is source evidence, not a responsive layout guess. Preserve `pl_1` through `pl_12` coordinates from `docs/m07-mini-games-source-map.md`. Each round combines one `Snd_<variant>/c_<round>.mp3` correct sound with three `i_<round>_<incorrect>.mp3` files; do not request a nonexistent `i_<round>_4.mp3`.
- Flying Instruments root rendering is not source-art evidence when the output is transparent. The source has 17 logical instruments: 16 repaired JPEG3 images plus viola vector child shape 0048. Logical IDs control the face, same-numbered `sound#` export, and family mapping; do not reorder the visuals independently. Level 1 uses IDs 1-17, while levels 2/3 select among four eight-ID source arrays. A deterministic fallback should use a documented recovered array, not the first eight runtime definitions. Classify the pointer/keyboard family targets as a documented fallback for the missing Tetris-like grid/timeline motion.
- Melody `saveKey5.exe` is gated by `_level1.seq_var == 3`, so game key 5 is earned after the third correct phrase rather than after an entire selected difficulty bank. Disable further note input while the timed demonstration or `CONTINUE`/`NEW GAME` feedback state is active, or clicks can advance the next sequence before the source transition. Track and cancel all scheduled note timers on stop, difficulty change, and route navigation so delayed one-shots cannot leak into another scene.
- Trivia's wrong-screen `AGAIN` button decrements `_level0.theQuestion` before returning to `doQuestion`; because that frame increments the question counter, the same prompt must repeat after a wrong answer.
- A route existing in `app/src/routes.ts` is not implementation evidence. `npm run assets:source-atlas` validates all 23 registered routes against existing source/evidence paths and writes `app/generated/source-atlas/contact-sheet.html`; defects must retain Linear follow-ups and Marcus approval gates.
- Do not regex-scan `routes.ts` or trust atlas-authored vocabulary/paths. The atlas gate parses route literals with the TypeScript AST, fixes the allowed classification schema in code, rejects repository/symlink escapes, enforces lifecycle and promoted-asset semantics, and requires exact `fallbackEvidence` for every `documented fallback` claim.
- Do not treat the two certificate EXEs as opaque Windows-only launchers. Each has a valid compressed `CWS` appended at byte `860160`; use `app/scripts/lib/flash-projector.mjs` and `npm run assets:certificates` to validate/inflate the final embedded payload before inspecting it with the SWF tools.

The projector parser validates the RECT/frame header and complete top-level tag stream, bounds decompression to the declared body length, and the certificate pass locks the recovered projector/SWF hashes, offset, sprite placement, print/quit actions, and certificate text before promotion.
